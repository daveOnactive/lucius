# Changelog

Changes to the Lucius instruction pack are recorded here. Versions follow the [semantic versioning policy](README.md#versioning), and entry dates use UTC.

## [1.0.1] - 2026-11-02

### Added

- Supplied Julius Grimoire artwork bundled as a local PNG README logo.

### Changed

- Allow task-scoped Graphify initialization when a substantive task needs it, while keeping CLI installation and project-document writes separately authorized.

## [1.0.0] - 2026-11-02

### Added

- Initial portable instruction-pack baseline for project-first frontend, backend, and full-stack work.
- Entry-point workflow and complementary security, structure, coding-style, QA, performance, database, and pipeline guides.
- Single-active-project selection with separate source, project-document, and Graphify-output context.
- Permission-conscious source discovery, project documentation, optional Graphify, and supplemental skill workflows.
- Project README with getting-started guidance, a guide index, the requested artwork source, and a manual release checklist.
- Authoritative `VERSION` file initialized to `1.0.0` and an `Unreleased` section for subsequent improvements.
